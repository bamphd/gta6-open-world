SOLMARA HEAT is an offline 3D open-world crime game set in the sun-soaked coastal city of Solmara: nine story jobs for wheelman Rook Calloway, stealable cars, five-star police with roadblocks and a helicopter, and a garage career loop across four distinct districts.

## Run it

```sh
node serve.ts
```
